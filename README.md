# 🎮 PokeDex — PPAW Week 6

Aplikasi web PokeDex sederhana untuk menampilkan dan mencari data Pokémon menggunakan **JavaScript Fetch API**. Proyek ini dibuat untuk memenuhi tugas individu PPAW Week 6 tentang JavaScript DOM, Event Handling, dan Fetch API.

## 📌 Deskripsi Proyek

PokeDex adalah aplikasi web yang memungkinkan pengguna menjelajahi daftar Pokémon yang diambil dari API publik [PokeAPI](https://pokeapi.co/). Aplikasi ini juga menyediakan halaman formulir untuk memasukkan dan menampilkan data profil Trainer.

Antarmuka dibuat menggunakan HTML, CSS, JavaScript, dan Bootstrap agar tampilannya lebih menarik dan responsif.

## ✨ Fitur

- **Daftar Pokémon:** Mengambil dan menampilkan data Pokémon dari PokeAPI.
- **Fetch API:** Mengambil data dari API dan mengolah respons JSON.
- **Pencarian Pokémon:** Mencari Pokémon berdasarkan nama.
- **Muat Ulang Data:** Memuat ulang daftar Pokémon.
- **DOM Manipulation:** Menampilkan data API secara dinamis ke halaman web.
- **Event Handling:** Menangani interaksi pengguna, seperti pencarian dan tombol muat ulang.
- **Form Data Diri:** Mengisi data profil Trainer melalui halaman formulir.
- **Tampilan Responsif:** Menggunakan Bootstrap dan CSS untuk menyesuaikan tampilan dengan ukuran layar.

## 🚀 Cara Menjalankan Aplikasi

1. Clone repositori ini atau unduh source code proyek.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Pastikan koneksi internet tersedia agar aplikasi dapat mengambil data dari PokeAPI dan memuat Bootstrap CDN.
4. Jalankan `index.html` menggunakan ekstensi **Live Server**.
5. Gunakan menu navigasi untuk membuka daftar Pokémon atau halaman Form Data Diri.

## 🌐 API yang Digunakan

Aplikasi ini menggunakan PokeAPI sebagai sumber data Pokémon.

**Endpoint:**

https://pokeapi.co/api/v2/pokemon?limit=20

Endpoint tersebut mengambil data hingga 20 Pokémon. Jika endpoint di kode JavaScript berbeda, sesuaikan dokumentasi ini dengan endpoint yang digunakan.

Dokumentasi resmi: https://pokeapi.co/docs/v2

## 📚 Materi yang Dipelajari

Melalui proyek ini, materi yang dipraktikkan meliputi:

1. Penggunaan Fetch API untuk mengambil data dari server.
2. Pengolahan respons API dalam format JSON.
3. Manipulasi DOM untuk menampilkan data secara dinamis.
4. Penanganan event pada input pencarian dan tombol.
5. Pembuatan form HTML dan pengolahan data input.
6. Penggunaan Bootstrap untuk membantu membangun antarmuka web.
